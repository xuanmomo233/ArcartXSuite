# QQBot 1.6 架构与维护

模块保留 OneBot 11 群服互联、宿主绑定、积分、红包、邮件兑换、管理界面和可选进程托管。

## 职责边界

| 层 | 入口 | 负责内容 |
| --- | --- | --- |
| 协议 | `onebot/OneBotClient`、`OneBotMessageCodec` | Universal WS、鉴权、回执关联、超时、消息格式、群预算、有界事件队列 |
| 应用 | `QQBotMessageGateway`、`QQBotService`、`QQBotCommandRouter` | 目的群、权限、玩家会话、限流、公开事件、业务路由 |
| 数据 | `QQBotRepository`、`JdbcQQBotRepository`、`QQBotEconomyStore` | 权威绑定快照索引、短期黑名单缓存、事务、审计与发奖状态 |
| 交互 | `QQBotUiService`、两个命令处理器、三份 UI | 会话令牌、二次确认、异步反馈、主线程 UI 更新 |

`QQBotModule` 只装配依赖并管理每轮生命周期。`SnowLumaProcessManager` 为独立的可选托管适配器，默认 external 不执行进程命令。

## 线程与背压

WS 读线程识别回执，不执行数据库业务。群事件进入单工作线程的 256 项队列；玩家发送进入 64 项队列。最多 128 个请求等待回执，群发送使用滚动分钟预算。超载明确拒绝，不无限堆积。

Bukkit 玩家对象、命令、UI 操作回主线程。玩家发送先捕获认证 connection ID 和 generation；排队后重新核对，以免旧连接的请求作用于新登录会话。UI 额外核对当前 Player 实例、面板会话和令牌。

公开接口的 CompletionStage 回调可能在传输线程执行，调用方不得阻塞回调。需要 Bukkit 操作时自行调度回主线程，不要在主线程等待 Future。

## 消息与隐私

Chat 通过 `PublicChatMessageEvent` 发布已接受、全服可见的公开消息。私聊、管理频道、范围频道及限制接收权限的频道不外发。原始 AsyncPlayerChatEvent 的 fallback 默认关闭；明确启用时也忽略取消事件，并在 Chat 接管时停用。

玩家 UI、玩家命令和公开聊天使用同一发送网关，遵守权限、准入、长度、冷却及群方向。管理通知和第三方通知只允许配置中的目的群。所有普通文本开启 CQ 转义；显式 @ 使用结构化 at 段。

QQ 群主或群管理员身份不自动授予游戏管理权。游戏管理需要 `admin.enabled` 与显式 QQ 名单；任意控制台命令还需独立开启 `admin.remote-console-enabled`，其默认关闭。自定义服务器命令模板同样只向可信名单开放。

## 结果与一致性

- OneBot 明确成功、明确拒绝、超时或断线后的未知结果分别反馈；未知结果不自动重播。
- 签到、积分转账、红包创建/领取/退款在同一连接事务中完成，失败回滚并明确报告。
- 兑换先在事务中冻结规范奖品 ID、收件角色、价格、限购额度和邮件列表，再逐项持久化发放状态。
- 外部邮件调用无法与本库组成原子事务。调用结果未知、部分发放或结果落库失败时冻结订单，禁止自动重发或全额退款。
- 发放节点持有数据库时间计算的心跳租约。健康节点的活跃订单不能被其他节点恢复或人工改判；关闭或过期节点的订单进入待核对。
- 管理员必须独立核对并附备注裁定未知订单。已确认发过任何邮件的订单不能直接全额退款。

QQ 资产按 QQ 身份归属，不随游戏角色删除。数据库迁移入口拒绝在线迁移；离线迁移需要全部相关节点停写并处理未结案订单。

## 安装与升级

配置版本为 6。`storage` 使用不透明同步策略保留独立数据库参数；旧迁移保留 mode，缺少有效独立 mode 时停止加载。默认模板不预置真实群、管理员或奖品。

三份新版界面导出至 `ui/qqbot_v2/`，保留原有自定义文件。继续定制时以新版协议为基础；不复用旧版客户端动作或列表结构。

托管操作只使用已保留的原生进程句柄，或同时匹配本地 owner token 与模块标签的容器。禁止按端口、通用 Node 名称或容器名称推断所有权。更新容器保留命名卷，Docker 数据目录为 `/app/data`。

## 验证入口

在项目根目录运行 `gradlew.bat :modules:qqbot:test :modules:chat:test`。测试使用真实 SQLite、回环 WebSocket 及模拟的 Bukkit/进程命令，不连接 QQ 或启动游戏服务。

UI 检查脚本为 `src/test/ui/check_qqbot_ui.py`，可传入本地客户端 jar 与 JDK 目录，对全部 Aria 表达式进行严格解析。

自动化测试不能替代真实 QQ 登录、Docker 镜像、MySQL 多节点、Mail 提供方及游戏客户端视觉/操作验收。
