# 内置房间构件的拼接约定

八个构件统一使用 7 格总高：相对 y=0 为完整地板，y=1～5 为房间净高，y=6 为屋顶。
procgen 的默认门洞净高为 5，走廊地板和屋顶因此分别对齐 y=0 与 y=6。
旧版构件总高为 4、5、6 格，混抽时屋顶和门框会出现高差。

本次只补齐墙体和内部空气层，将原屋顶移到 y=6；地板、出生点、怪物与奖励锚点保持原高度。
房间宽深可以不同，随机旋转后仍按网格中心对齐。
自定义构件应包含一层地板和屋顶，并将地板放在选区最底层；门洞从地板上一格开始。
引擎会将门洞高度限制在屋顶之下，但不会自动改造自定义构件的楼层或装饰。

南北向门洞使用 z 墙面坐标和 x 沿墙坐标，东西向则使用 x 墙面坐标和 z 沿墙坐标。
门洞与走廊生成完成后，战斗房仍按玩法规则暂时封门，清房后开放；铁栏封门与石砖墙未挖开是不同状态。

修改内置资源后，已有服务器的 data/abyss/room-sets/example 不会被启动自动覆盖。
部署时需备份并同步对应的 .region.yml，再重载模块；已经生成的实例不自动重建。
